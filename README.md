## 🔬 Projects Overview

### 🖼️ Computer Vision

A comprehensive exploration of classical and modern computer vision techniques across four homework assignments.

<details>
<summary><b>HW1 — Feature Detection & Tracking</b></summary>

- **FAST/BRIEF Detector**: Implementation of keypoint detection and binary descriptors
- **Hough Transform**: Line and shape detection using Hough space
- **Object Tracking**: Translation and rotation tracking experiments

📁 Location: `cv/hm1/`
</details>

<details>
<summary><b>HW2 — Image Segmentation & Transformations</b></summary>

| Task | Description |
|------|-------------|
| Text Segmentation | Separating text from background using morphological operations |
| Object Counting | Counting objects in images using watershed algorithm |
| Object Segmentation | Image segmentation techniques |
| Affine Transformation | Geometric transformations |
| Perspective Transform | Homography and perspective correction |

📁 Location: `cv/hm2/`
</details>

<details>
<summary><b>HW3 — Object Tracking & Retrieval</b></summary>

- **Lucas-Kanade Tracker**: Optical flow-based object tracking
- **Template Matching**: SSD-based template tracking
- **Kalman Filter**: State estimation for motion prediction
- **Mean Shift / CamShift**: Color histogram-based tracking
- **Image Retrieval**: Content-based image search

📁 Location: `cv/hm3/`
</details>

<details>
<summary><b>HW4 — 3D Vision & Camera Geometry</b></summary>

- **Ellipse Detection**: Finding and visualizing ellipses in images
- **Camera Calibration**: Smartphone camera intrinsic/extrinsic parameter estimation
- **Epipolar Geometry**: Computing epipolar lines for stereo vision
- **3D Reconstruction**: Reconstructing 3D scenes from 2D images

📁 Location: `cv/hm4/`
</details>

### 🧮 Linear Algebra

**Recommendation System Project**

Implementation of a movie recommendation system using matrix factorization techniques and collaborative filtering on the MovieLens dataset.

**Key Techniques:**
- Singular Value Decomposition (SVD)
- Cosine similarity
- Polynomial feature transformations
- Cross-validation for model selection

📁 Location: `linear_algebra/`

---

### 🤖 Machine Learning

**Unsupervised Feature Extraction**

A comparative study of unsupervised representation learning methods for feature extraction.

| Method | Paper |
|--------|-------|
| **Deep InfoMax (DIM)** | [Learning deep representations by mutual information estimation and maximization](https://arxiv.org/abs/1808.06670) |
| **Auto-Encoding Transformations (AET)** | [AET vs. AED: Unsupervised Representation Learning by Auto-Encoding Transformations rather than Data](https://arxiv.org/pdf/1901.04596.pdf) |

**Repository Structure:**
- `dim/` — DIM implementation with training and inference scripts
- `aet/` — AET implementation using AlexNet and BlockNet architectures
- `notebooks/` — Visualization and analysis (manifold visualization, similarity search)

📁 Location: `ml-project/`

---

### 🔍 Responsible Data Science

**Interpretability of Fake Face Discrimination**

Investigating the interpretability and transparency of CNN models in detecting fake faces generated by GANs.

**Components:**
- **StyleGAN Generator**: Generating synthetic face images
- **StarGAN Discriminator**: Discriminating real vs. fake faces
- **Visual Interpretability**: Understanding model decisions

**Visualization Techniques Explored:**
- Vanilla Backpropagation (with Smooth Gradient)
- Guided Backpropagation
- Gradient-weighted Class Activation Mapping (GradCAM)

**Team Members:** Anastasiia Khaburska, Anton Shcherbyna, Vadym Korshunov, Yaroslava Lochman

📁 Location: `responsible-ds-final-project/`
